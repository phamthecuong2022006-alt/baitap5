# Bài tập Razor Pages

## Bài 1 - Hiển thị danh sách sản phẩm
Thư mục: `Bai1_Product`

Tạo lớp Product gồm Id, Name, Price và hiển thị danh sách sản phẩm bằng foreach dưới dạng bảng HTML.

## Bài 2 - Kiểm tra cuối tuần
Thư mục: `Bai2_Weekend`

Tạo trang Razor kiểm tra ngày hôm nay có phải Thứ 7 hoặc Chủ nhật hay không.

Mỗi bài là một ASP.NET Core Razor Pages project độc lập.
